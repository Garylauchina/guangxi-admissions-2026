## 广西覆盖和证据缺口

39所强基校中，16所已取得2026年广西范围或分数证据，19所广西具体投放范围待核实，4所已读取的2026招生省份清单不包含广西（中央民族大学、东南大学、电子科技大学、国防科技大学）。未知不表示不招生，全国39校名录也不表示39校全部在广西招生。

所有强基 `majors` 均按全国简章或学校全国专业介绍整理，不能当作广西实际专业清单。部分官方专业表以图片或附件发布，本次只登记已读到的项目；`majorsScope`、`subjectRequirements` 与 `evidenceGaps` 标明未补齐处。只有取得具体省份依据才将强基 `guangxiStatus` 设为confirmed。部分面向全国的少年英才项目确认的仅是申请范围，不代表广西有固定名额。

广西强基分专业人数尚未取得可复核的公开数字，因此 `planCount` 全为null，不能显示为0。部分特殊项目的 `nationalPlanCount=100` 是全国规模上限，不能算作广西计划。更完整的分省计划通常需考生查看当年报名系统；本次没有访问个人账号。

## 已核实的分数

共24条2026年广西分数记录，来自中国农业大学、哈尔滨工业大学、中国科学技术大学、厦门大学、中南大学、重庆大学、兰州大学7校。记录按专业或官方公布组别保留，不把同一专业组擅自拆成多个专业分数。

每条分数保留 `major / score / scoreType / formula / note / sourceIds`，并附原始来源链接。三种口径必须分开展示：高考原始分入围线、校方加权入围线、含校考的综合录取线。校级 `score` 统一null，防止将异质分数压成一条“院校录取线”。没有核实分制或公式的记录，`maxScore` 或 `formula` 保留null并注明不能与750分直接比较。

例如：中农广西入围610为高考原始分，哈工大数学类入围673.8为加权成绩、录取84.7为综合成绩。兰大广西历史584、生态589.8、核化工与核燃料工程644.3由官网公告图片人工核对；后二者含学科加权。同校其他专业表格空白未补成0，也未推定分数。

## 竞赛与政策处理

2026年奥赛国家集训队保送资格和高校强基竞赛破格是不同通道。高校认可的学科、全国决赛奖级、应届生条件、单科破格标准差异保留在逐校条目中。竞赛获奖不直接等于保送或录取；强基破格一般仍涉及高考及校考。

教育部2025—2028学年全国性竞赛名单包含47项。该名单有效期覆盖2026，但列入名单不代表取得高校录取资格。完整名单链接指向教育部正式通知；本次没有将赛事宣传或培训机构解读视为招生依据。

4条少年英才项目的简章虽可能发表于2025年，标题和适用招生年份均为2026，不能因发布时间而改写招生年份。本库为2026历史记录，已过报名时间；不能直接用作2027报名日期或资格结论。
