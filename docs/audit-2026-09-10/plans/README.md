# 广西 2026 年专业计划深审交付

> 本目录保存核验报告；下文复现程序及冻结输入位于 [`scripts/collectors/audit-2026-09-10/plans/`](../../../scripts/collectors/audit-2026-09-10/plans/)。校正后的当前数据位于 `site/data/`。

本目录只含公开招生资料、既有公开网站数据快照及审计结果，不包含考生个人资料。审查日为 2026-09-10。本轮未编辑或部署网站。

## 接入顺序

1. `corrected-plans.json` 是原 **14 校、1584 条基础数据的整批替换**，修正后为 **1497 条**；不是全站 1684 条替换集。用 `baseline/research-plans.json` 的 ID 集删除旧基础记录，再加入此文件。
2. 对此前网站额外的玉林教师计划应用 `supplemental-plan-patch.json`：删除 `deleteIds`，按 ID 更新或加入 `upsert`。原 29 行合并为 27 行、85 人。
3. 保留网站其余两校的 71 条原有补充，以及其他代理新交付的独立计划。仅应用本目录结果，原站 1684 条会成为 1595 条：1684－87－2。
4. 将 `new-sources.json` 追加到来源表。原 `sourceId` 保持最初计划人数来源；`fieldSourceIds` 指向新增字段证据。专业组、选科、费用来源应允许用户查看相应补充来源。
5. 排除记录进入 `excluded-plans.json` 审计档案，不进入普通文化分计划筛选。未删除来源或原始记录。

## 已修正问题

- 广西师范大学 67 条“预科直升批”退出当年高考可填报计划；6 条地方公费师范生补正确类别。其中 5 条招生简章明确列明专业的计划补免费学费、四年学制；科学教育 12 人与该简章列专业不同，仅根据计划性质修类别，没有套用费用学制。
- 玉林师范学院 20 条艺术体育计划退出普通文化分筛选。原解析误把“师范类/普通类”专业性质当成高考科类；招生后的艺术体育录取表直接确认其类别。排除仅针对玉林明确来源，未把其他学校同名运动康复等普通类专业排除。
- 53 条首选科目单独必选的记录纠正为再选不限。`track` 保留物理或历史；`requiredSubjects` 只存再选科目。逐项检索了所有现有选科原文，未发现需要从 all 改 any 的明确原文。
- 玉林“网络新媒体”2 条按章程和录取表修为“网络与新媒体”；原计划同页选科表明确为不提科目要求，补回再选不限。
- 玉林人工智能 2 条源内冲突：原文列“物理、化学”却写“3 门均须选考”。保留明确出现的化学条件和完整原文，`subjectRule=unknown`、`requirementStatus=source-conflict`，不擅自补生物，也不显示完整条件已核实。
- 玉林 89 条基础计划均获得官方公告直接列出的真实专业组，补齐 89 条学费、学制。匹配不使用分数字段；同名专业出现多组时用原计划类别、科类及人数区分，有歧义则不配。3 条原计划人数与后续公告不同：园林物理 42→43、数学物理 209→219、汉语言文学历史 208→218。保留原人数，差异另见 `plan-count-differences.json`。
- 广西中医药大学官方 2026 分组原图明确 47 条单一组码。2 条定向计划只列历史 401—414、物理 451—464 区间，原招生计划没有拆地区，仍保持 `group=null`。填批次时，仅在直接获得组码后，按省考试院的学校代码＋科类＋组码唯一对应批次；未从分数推组。
- 广西中医药 40 条本科表数据原注释包括预科直升，无法从总人数拆出当年高考可填数。保留公开数，并设 `plannedCountScope=includesPreparatoryProgression`、`currentGaokaoSeatsKnown=false`，界面不得把这些数称为当年可填席位。章程补定向免费、免费预科阶段免费，以及其余明确专业的收费标准。本科费用是学分制预缴额，已在值中说明。按官方图逐行补42条明确的色盲色弱禁忌；健康服务与管理、医学信息工程及预科空白备注没有补禁忌。5+3培养保留总程，另列本科阶段5年。
- 广西医科大学官方 2026 FAQ 核实四个招生批次，修正 76 条计划的批次。定向医学生只得到本科提前批大类，具体小批次保留待核。药学中澳项目修为“学分互认联合培养项目”，不混同法定中外合作办学。
- 桂林电子科技大学 4 条明确中外合作项目补章程费用：数字媒体技术 45000 元/学年，其余三专业 60000 元/学年。普通本科与应用型本科收费不同，原计划未充分标明口径，未整批套用 6000 元。
- 广西财经学院 4 条预科的 API 学制字段为 4、层次为本科，未区分预科与本科阶段。保留 `sourceDuration=4`，显示 `duration=null`，标 `durationStatus=source-stage-ambiguous`，避免称“预科四年”。原已修复的 19 条精准专项及中外合作类别保留。
- 玉林教师补充：物理 452 组陆川物理学原计划一格 5 人，录取表分为 4＋1；历史 430 组博白义教应用心理学原计划一格 4 人，录取表分为 1＋3。分别合并，保留独立证据；后续征集不与原计划相加。27 行全部依原县×专业×科类格子补再选条件，优师/地方公费类别依原表备注区分。

## 差异与验证

`field-corrections.json` 包含 1079 次字段修正记录，每次均列原值、新值、计划 ID、官方来源及定位。含一个字段多次处理的中间变更，以及玉林额外 27 行补丁。

最终基础集相对 1584 条基线：274 条保留记录发生字段修改，另排除 87 条。净字段差异汇总见 `audit-findings.json.baselineToFinalFieldDifferences`；专业组已知由 293 增至 429，新增 136。未变更基础集任何一条原始公开计划人数。

`verification.json` 的独立核验包括：ID 分割准确、原人数保留、教师合并前后计数核对、来源文件 SHA-256、12 个专业计划 API 条件查询和南宁师范完整接口的年份/广西省份/行人数与官方汇总相等。核对的是公开查询条件的覆盖，不等于学校全部招生类型或全区院校覆盖。

旧基础 30 份来源本轮已重新读取，详见 `source-recheck-results.json`。新增 10 份官方来源的年份核验见 `source-year-checks.json`。全部记录为 2026 年，未通过修改年份复用 2025 记录。

## 仍需标注的缺口

这仍是 14 校基础集及额外玉林教师计划的深审，不是广西全部高校计划全覆盖。原站东北石油大学、重庆工程学院 71 行本轮只作结构检查，原来源事实复核由根任务与录取线代理另行负责。

- 广西大学 2026 分组指南公开的是“一组、二组”等校内序号，不是广西三位组码，不能转换。对应普通专业选科已与原 API 比较，未发现冲突，组码仍缺。
- 广西医科大学 2026“专业分组一览表”官方入口正文为空，页面只有其他装饰或二维码图片；仅有标题不构成组码证据。76 行再选条件仍待核。
- 广西师范大学分组导航旧页为 2024 年，其图片是装饰图；未当 2026 分组使用。154 行现存计划再选要求仍缺。
- 广西民族师范学院、北部湾大学、百色学院仍有批次及组码缺口；广西民族大学、南宁师范大学、广西财经学院及广西工程职业学院仍缺组码。具体每校字段缺口数量列在 `audit-findings.json.schoolStats`。
- 桂林理工的 pageNo=2 请求返回与 pageNo=1 相同表格；接口没有给出可核实总页数，不能声称“第二页为空”或以此证明全校全部计划覆盖。
- 广西中医药 4 条预科批次仍待核；2 条定向既缺细批次也没有可关联单组。普通预科具体学费还缺。
- 学校公开的分省总计划可能含预科直升、后续调整；不能把后续录取人数逆向当成最初计划数，也不能因某专业组投档分相同就声称专业属于该组。

## 复现与发布范围

`collect.py`、`fetch_public.py`、`extract_tables.py`、`audit.py`、`verify.py` 都使用本目录相对路径，无旧私人研究目录、2025 采集目录依赖。

1. 保留本目录 `baseline/` 的公开数据快照及 `public-request-manifest.json`。
2. `python3 fetch_public.py` 按 40 项公开 GET/POST 清单采集，无账号、无登录绕过。服务端更新可能使原 SHA 变化，应作为新审计批次，不能覆盖历史哈希后继续声称旧核验通过。
3. 安装 `pandas`、`lxml` 后运行 `python3 extract_tables.py`，展开官方合并单元格；基础 HTML 表由采集器同时存档。
4. `python3 audit.py` 从基线和当前原文重建纠错集；中医药图片转录逻辑及其逐条展开结果在脚本和 `gxtcm-group-transcription.json`，复现者应对照官方原图视觉复核。
5. `python3 verify.py` 执行独立人数、来源、年份、省份、合并核验。

原始 HTML、JSON、PDF、图片均留在本地 `raw/`，根任务按公开仓库发布清单选择是否发布；不要混入相邻旧私人项目文件。本目录源码及数据都可独立公开。`baseline/site-cutoffs.json` 只用来验证批次字段，不参与院校专业组码推断。
