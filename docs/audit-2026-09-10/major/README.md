截至 2026-09-10，本目录包含 **13 校、720 条专业录取最低分**，其中本轮新增 **8 校、467 条**，旧 5 校 253 条全部保留并逐条重读官方源表。另保存广西工程职业学院 **81 条专业投档最低分**，不计入实际录取覆盖。没有使用 2025 数据改年份、学校最低线代替专业线或私人学生信息。

交付文件：

- `corrected-major-cutoffs.json`：720 条专业实际录取结果；包括普通类及明确标识的专项、民族班、合作、定向等类别。
- `major-filing-cutoffs.json`：广西工程职业学院 81 条专业投档最低分，必须与实际录取表分开展示。
- `new-plan-supplement.json`：华北水利水电大学 16 条、辽宁轨道交通职业学院 4 条，明确计划列合计 104 人。来源是录取结果公告，未确认与最初计划发布版本完全相同；不是征集剩余计划，也没有以录取人数替代计划。
- `sources.json`：44 个已使用官方来源或限定范围检索证据，包括图片直链、父公告、公开接口参数、来源哈希及访问时间。
- `findings.json`：源表冲突、被排除行及 13 校限定范围负面检索/待解析证据。
- `school-reviews.json`：13 校已收入结果的复查摘要，以及另 13 校的限定范围查找结果。它不声称全省所有学校均已逐校人工复核。
- `quality-report.json`、`validation.json`：解析抽核、字段和来源完整性检查；本轮结果 PASS。

关键口径：

1. 重庆三峡医药高等专科学校物理类“医学检验技术”“预防医学”原表录取人数为 1，但最低分与最高分不同。原值保留，`scoreComparable=false`，并在 `scoreEvidenceGaps` 说明，网站应排除其分数比较。
2. 玉林师范学院的原文出档分冲突以及重复分列的公费子计划身份缺口，保留在 `conflictFields` 和备注中。其明确专业最低分仍可证，因此 `scoreComparable=true`。身份未解决的行不得静默合并人数。
3. `rank` 只有原表逐专业明确列出的“最低分位次”才填写，本轮共 214 条：华北水利水电大学 16、百色学院 122、广西医科大学 76。桂林航天工业学院的分段汇总位次没有复制给各专业；本目录也不从一分一档推算精确专业位次。各源未明确的加分/同分口径仍未知。
4. 广西医科大学接口有 `dataSource` 学校汇总和 `major_data_source` 专业明细。前者虽然带一个专业名称，仍整批 6 条排除；专业明细中另排除 1 条预科。接口 `num` 的公开列配置未标明人数口径，保存在 `unclassifiedSourceCount`，不填计划数或录取人数。
5. 百色学院录取情况公告里的普通、精准、民族班图片列“最低分”；公费师范图分数子列名为“投档成绩”。北京体育大学官网“普通类专业录取分数线”也使用“投档成绩”子列。两校均按录取结果公告来源保留该源口径，不解释为艺术或体育综合分。
6. 未注明轮次的专业结果为“录取汇总（轮次未分）”，不能标首轮。桂林航天工业学院标题明确“正投”，才标首轮；旧玉林与齐齐哈尔的征集说明保留。
7. 普通记录备注不包含无关专项关键词，避免前端资格筛选误判。跨专业通用分类方法放在 `source.method`，单条资格由 `admissionType` 和实际专业原名表达。
8. 提前批细分不合并：广西医科大学 22 条保留“本科提前批其他三类”，玉林师范学院 32 条为“本科提前批其他一类”，百色学院 16 条保留原图“本科提前批其它类（公费师范）”；百色未公布进一步一/二/三类，因此 `batchDetailGap` 明确留缺，不能推定。全表已不再有笼统“本科提前批”值。

复现与依赖：

- 获取、HTML 解析、构建和验证使用 Python 3 标准库，无第三方 Python 包依赖。
- 百色学院四张录取图片已全行人工核读；`bsuc-*-transcription.*` 是公开可复核转录。`ocr.swift` 为可选的 macOS Vision OCR 辅助工具，不能代替目视核对，不是重建数据必需依赖。
- 本地 `raw/` 保留原页、图片、API 响应及哈希，不随网站发布。公开复现只需脚本、基线 JSON、转录文件及 `public-fetch-manifest.json`；不要复制含探索性请求的整个工作目录。

从本目录运行：

```sh
python3 fetch_evidence.py --manifest public-fetch-manifest.json
python3 build_findings.py
python3 build.py
python3 validate.py
python3 finalize.py
```

`public-fetch-manifest.json` 列出构建使用的 44 个来源请求及本轮哈希；重新获取后如果官网响应内容改变（包括动态 API 元数据改变），获取脚本会标记 `changed` 并停止，要求先比较新旧事实再更新哈希，不静默把变化当作相同证据。旧玉林资格辅助源本轮复用此前已核验的两张考试院本科首轮表，未重复开展 16 表审计。验证器在当前工作树可读取其原缓存；公开获取清单会把这两份辅助原页下载到当前 `raw/`，因此可独立运行。

最终检验包括：720/81/20 三份表独立行数、所有必需字段、唯一 ID、数值范围、全部主来源/辅助来源/父来源引用、44 份原始文件 SHA256、普通类备注资格词回归、两条分数不可比标记、玉林可比标记、明确计划列及限定范围检索证据。结构校验通过不代表全省专业结果已收齐；未取得数据的院校仍需展示缺口。
