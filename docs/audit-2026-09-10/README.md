## 主要修复

- 根据官方专业与组码对应表新增 136 条真实组码；校验同时要求年份、院校代码和名称、科类、批次与组码一致，拒绝重复匹配键。
- 玉林师院两项县域公费计划依据最初计划表合并为 5 人和 4 人，保留 4＋1、1＋3 的公告分列证据。三项最初计划与后续公告人数不同，保存两个版本，不覆盖原计划。
- 中医药大学 40 条本科公布人数含预科直升、没有拆分，醒目标明不能作为已确认高考可填人数；补齐原图 42 条明确体检禁忌。广西财经 4 条预科学制不再将接口本科字段“4年”当作预科阶段学制。
- 医大 22 条定向专业及对应汇总计划保留“本科提前批其他三类”；百色 16 条保留原图“本科提前批其它类（公费师范）”，进一步子类仍待核。
- 重庆三峡医专 2 行录取人数为 1、最高最低分却不同。保留原值与说明，暂停分数比较。玉林原公告的出档分冲突不污染考试院组线，实际专业分保留独立来源口径。
- 新增专业录取资料来自桂林理工、桂林航天、广西医大、百色、华北水利、重庆三峡医专、辽宁轨交及北京体育大学。专业位次只录入原表明列的 214 条，不从组位次或一分一档推算。
- 广西工程职业学院 81 条只称“专业投档最低分”，[另存事实文件](../../site/data/major-filing-cutoffs.json)，不冒充专业实际录取线。
- 强基补齐中科大、厦大、中南六条公式，补清华、复旦、天津大学、湖南大学、华科广西证据；华科入围原表小数后的语数外排序码与总分分开保存。重庆大学两条原已采数值本轮无法重读，明确保留复核缺口。
- 页面新增逐校缺口查询与专业详情缺口提示；未知分数开关在不限分数时仍有效；专业录取页默认显示各轮次并保留口径。导出备选同时附计划及所引用组线来源。
