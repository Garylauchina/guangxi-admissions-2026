## 复现

使用 Python 标准库。按顺序执行 `collect.py requests.json`、`collect.py requests-2.json` 至 `collect.py requests-8.json`，随后 `tongji_public.py`、`build.py`。这些 manifest 记录本轮实际观察的前端 URL 与参数；若高校日后更换入口或发布 2026 分数，构建中的断言应失败，须重新核对，不能继续沿用本次空结果结论。

可在网站仓库外运行其 `scripts/import-major-score-batch.mjs` 对本目录做预检；不要加 `--apply`，除非负责整合的任务已授权写入。

本地 `raw/` 仅供资料复核，不公开。发布严格使用 `PUBLIC-FILES.json` 白名单，不递归复制整个工作目录。
