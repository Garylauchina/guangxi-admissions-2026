# 2026 广西专业实际录取分：2026-09-11 批次 A

本包审查 9 校，新增 2 校 38 条可比较的高考总分录取记录。中央民族大学 35 条中，普通本科 28、民族班 5、国家专项 1、合作办学 1；西交利物浦大学 3 个正式招生大类，对应实际录取 110 人。其余 7 校未取得符合 2026 广西单专业口径的记录，均保留逐校核查结论，不能把“已检查”理解为“已补齐”。

## 数据口径

- 仅 2026 广西历史、物理两科；正式招生大类可作为原招生单元保存，不拆成大类内具体专业最低分。
- 中央民族大学的 `score/mincj`、`sourceMaximumScore/maxcj`、`sourceAverageScore/avgcj`、`rank/minwc` 直接一一映射。官方表头明确最低分排名，保留字段来源。页面说明分数为小数时向下取整，采集值不二次加工。
- 中央民大公开选项为历史普通本科/民族班、物理普通本科/国家专项/合作办学/民族班。6 个响应的 `total` 等于 `rows` 长度；前端不使用分页参数。体育科类被排除，未查询体育专业。没有把录取概况表当专业分。
- 中央民大民族班只招少数民族考生；国家专项保留资格；数据科学与大数据技术的合作项目由章程明确为内地与港澳地区合作办学。语言类、合作办学的转专业或语种限制有直接章程证据。
- 西浦广西表的“招生专业组”列实际填的是历史+不限、物理+不限、物理+化学，不能转换为省编组码。`plannedCount` 和 `admittedCount` 分别读取各自原始列；本次恰好相同不等于两者概念相同。
- 西浦章程明确按大类填报，招生大类名称与入学后就读专业无直接关联；完成第一学期后选择专业受课程和成绩条件约束。其大类分数不能解读为入学后每个专业的录取门槛。
- 全部记录保留 `group:null`；来源未按首轮/征集分开，统一“录取汇总（轮次未分）”。来源没有直接列出广西精确批次，保留批次待核。未利用本库相同分数推断组码、批次或轮次。
- 比较基于普通高考 750 分总分尺度，政策加分按学校章程执行，表中未单列加分处理；不声称是裸分。能够比较不代表可以保证录取。排名是学校公布原值，不另行推算同分位次。

## 文件与复现

`major-cutoffs-upsert.json`、`sources.json`、`school-audit-notes.json` 可交给当前专业分导入器进行只读预检与集成。`QA.json` 是本批内部字段及原值校验结果；独立复核另列。

在本目录执行：

```sh
python3 build.py
python3 verify.py
```

两步从公开冻结证据离线重建本批文件，无旧研究目录或私人路径依赖。冻结证据包含干净 API JSON、广西表转录、查询结果摘要及来源快照。

在线复采：

```sh
python3 replay.py
```

仅请求 `public-fetch-manifest.json` 明列地址和公开前端字段。使用正常匿名会话；不登录、不解验证码、不执行访问验证挑战。请求值只含省份、年份、科类、招生类型及公开学校/表 ID。响应保存在本地 `raw/`，会话不写进请求清单。预期的 HTTP 412/483 也是本轮证据；新的正文/状态变化都会提示重新人工审查，不会自动更新已审数据。动态网页 hash 变化不一定代表数字变化，仍须审查。

`freeze_evidence.py` 用于人工复核新响应后再次提取公开证据；只访问本目录 `raw/`。它不用于替代独立审核，网页变化后必须更新、审查与运行对应断言。不要仅因为脚本运行成功就提高缺口学校的覆盖声明。

来源 `responseSha256` 是收到的原响应字节 hash；`sha256` 是归档字节 hash。JSON 删除敏感键后格式化，因此两者可能不同；HTML/PDF 没有重写，两者相同。原始网页、验证码/挑战页面及 PDF 均留在本地 `raw/`，不在发布白名单。公开 JSON 归档及原响应字段小摘录只供事实核对，可与对应 `sha256` 直接校验；提取表与摘要是衍生证据，不冒充原网页字节。

来源采集时间、复核时间公开为北京时间 `+08:00`，本地原始请求元信息保留 UTC。`PUBLIC-FILES.json` 是唯一公开白名单；请勿递归发布本目录。脚本不含账号、Cookie、认证头值、会话或用户目录。
