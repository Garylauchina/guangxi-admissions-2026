# 2026年广西高校实际专业录取分：2026-09-11 C批

本批只研究数据，不修改网站、招生计划、Git或发布设置。读取基线为现站816条、17所高校；避开本轮前20校目标。

## 交付

- 94条实际专业最低分：江西水利电力大学18、四川旅游学院5、山西大同大学8、福建商学院63。
- 首选历史34条、物理60条；普通类90、中外合作办学2、定向培养军士2；原表实际录取人数合计271。
- 仅四川旅游学院5行的专业组码为分数原表直接给出。其余89条group为null，不按校内组序号、选科、组投档线推断组码。
- 全部保留“录取汇总（轮次未分）”。公告写录取结束不能证明首轮，也不能据7月发布日期或计划录取数相等推定首轮。
- 从录取统计表读取人数仅用于验证真实录取，未写计划字段；未替换或修改招生计划。

## 来源与原表定位

`sources.json`的官方URL、查询条件、访问时间、原响应SHA256和本地归档SHA256用于追溯。`evidence-rows.json`逐项保留源表行值，数据表的sourceTable/sourceRow/sourcePage和fieldSourceIds可定位。

江西水利电力大学两公告分别有批次汇总表和专业表：只导入第二张专业表，4条总体汇总在`excluded-records.json`。HTML采用独立嵌套表上下文读取并展开合并单元格，避免CMS外层布局表遮蔽内层真实表。

福建商学院2页PDF已由pdfplumber读取和渲染，人工查看两页图像核对：标题“福建商学院2026年本科专业招生录取情况表（广西-143）”，表头为序号/专业名称/科类（组别）/计划数/录取数/最高分/最低分/平均分/省控线/高出省控线分值。第1页序号1—43，第2页44—63，连续无缺行；科类（组别）是“历史+不限”“物理+不限”“物理+化学”，不是广西3位组码。第23行历史零售业管理计划2人、实际1人、最高最低平均均491，按1名真实录取保留。网页发布时间2026-07-20，PDF年省和正文吻合。完整PDF、渲染图与自动提取档只保留本地，不列入公开白名单。

## 必须保留的限制

- 江西水利电力大学原表的本科最低分位次存在跨行次序异常，如物化水土保持最低544分列38324、测绘最低543分列37700。18条rank统一为null，原值放sourceMinimumRank、rankComparable=false，不能用于位次比较。分数的最高/最低/平均和真实录取人数自身检查通过；未根据位次倒改分数。两条军士专业也暂不启用该校位次。
- 江西水利电力大学英语专业仅招英语语种；土木工程中外合作为荷兰萨克逊应用科技大学项目，年学费25000元且不可转普通专业；两条定向军士年学费8000元，政审体检等资格明确。原公告未单列军士性别，不推断。
- 四川旅游学院建筑电气与智能化中外合作项目：英语单科至少85分，仅录取填报本专业志愿者，入学后不可转入其他专业。烹饪与营养教育要求裸眼或矫正视力4.8及以上且无色盲。要求由2026章程直接支持。
- 分数按普通750分高考总分口径处理，允许学校认可的政策性加分；未声称是剔除加分的裸分。各校章程支持进档成绩用于专业录取。只停止有问题的位次比较，未因未单列裸分标记分数不可用。
- 4校“collected”只指完整覆盖列明原表的广西专业行，并不声称全年所有轮次、专项类别和细则全部公开。

## 复现与检查

1. 使用Python3运行`collect.py`，它按`requests.json`有界读取官方网页、公开表单和PDF；只保存响应内容/安全查询参数，不存Cookie或请求头。JSON会话字段移除。WAF原页面可能含网站自用访问值，因此raw目录从不公开。
2. 用具备pdfplumber的Python运行`build.py`。它从原始HTML/PDF重新生成94行、来源、核查记录、排除记录和QA.json，非手录数据表。
3. 对repo最新`import-major-score-batch.mjs`执行不带`--apply`的预检。检查报告另存`importer-preflight.json`；本批禁止自行应用到站点。
4. `verify.py`检查全部94条与源单元格一致、四校身份/排重、来源引用、已知计划字段缺失、数值与人数、公开白名单内没有会话秘密。`QA.json`和`verification.json`记录结果。

只公开`PUBLIC_FILES.json`逐个列出的文件。完整网页、PDF、渲染图、WAF响应、临时缓存不上传。
