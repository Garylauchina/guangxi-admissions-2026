## 功能

Node.js 测试覆盖真实数据加载、分数和位次输入、越界错误、院校/专业搜索、两科隔离、选科条件、资格限制、分轮专业录取查询、备选保存、CSV导出、详情对话框、导航和数据加载失败提示。特殊成绩显示中文分数类型和各自来源；普通与加权/综合分不混算。

静态入口、所有本地资源、来源外键、年份、唯一编号、已知计数与数据中的私人信息泄漏模式有独立检查。本站没有运行时外部脚本、登录或分数上传。

页面交互测试使用 DOM 模拟环境；不是实际手机或浏览器像素级视觉验收。响应式样式已实现。Pages 上线后的 HTTP 状态、资源与数据内容还需按实际部署进行核对，部署结果以 GitHub Actions 和线上访问验证为准。
