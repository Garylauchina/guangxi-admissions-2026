其余两校已有有效本年来源但未入计划行：

- 广西科技大学：2026 分省人数 PDF 与专业组 PDF 分别可取，但未明确把人数拆到历史/物理与资格类别。专业组表还明确组设置适用普通类型，不能把分省合计硬拼到这些组。2026 广西公开查询返回空。本批不猜分配。

`source-catalog.json` 对这五校分别标 `collected` 或 `source-found`，均附真实官方入口和来源 ID。`QA.json` 含每组总数、学校总数对账、抽核行及排除记录；`validation.json` 独立核对字段、业务唯一键、源行、全部来源哈希、待核标签和收录边界。

复现文件：`build.py`、`html_tables.py`、`build_glmu.py`、`validate.py`、`fetch_evidence.py`、`public-fetch-manifest.json`。除桂医 PDF 解析需要 `pdfplumber` 外，均只使用 Python 3 标准库；也可保留已人工核读并生成的 `glmu-extension.json` 用标准库重建。`raw/` 原始文件不随网站发布。

```sh
python3 fetch_evidence.py --manifest public-fetch-manifest.json
python3 build_glmu.py
python3 build.py
python3 validate.py
```
