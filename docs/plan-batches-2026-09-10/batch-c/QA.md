## 文件与复现

正式并入：plans-upsert.json、sources.json、source-catalog.json。目录状态采用collected、source-found、entry-only、unavailable。可同时发布QA.md、QA.json和复现脚本；不要将evidence中的原始网页、PDF、图片或完整检索文本上传公开仓库。pending-hznu-plans.json仅为待复核候选，不能批量合并。

本地复现：

```sh
python3 fetch_sources.py
python3 build_batch.py
python3 validate_batch.py
```

脚本均只操作本目录。parse_tables.py展开HTML的rowspan和colspan后，以官方表的省份段和科类选取，不从录取人数或征集余额产生初始计划。build_batch.py对两校计划人数与艺术剔除数做闭合断言；validate_batch.py核对身份、来源、资格标签、空值语义、人数、候选隔离和下载文件摘要。网站首轮表仅用于只读身份兼容性核验。

高校初始发布计划仍可能受省招生部门最终公布及正式调整影响；此次未把任何征集剩余人数或录取人数当作初始计划。
