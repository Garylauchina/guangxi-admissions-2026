# 批次 A：广西既有学校初始计划与专业组公开证据

审查时间：2026-09-10。限定广西大学、广西师范大学、南宁师范大学、广西民族大学、广西医科大学、桂林电子科技大学、桂林理工大学、广西财经学院 8 校。未编辑网站、发布或拓展录取线。

## 可接入交付

- `plans-upsert.json`：**11 条原 ID 完整记录**。仅将广西民族大学明确的中澳 2+2、3+2 学分互认培养项目从普通类修为“学分互认联合培养项目”。证据为重新读取的 2026 广西初始计划 API 的 `major`、`exam_direction` 等公开字段，`field-changes.json` 有逐条源行 ID 和字段值。计划数、组码、其他已有数据均保留。
- `source-catalog.json`：8 校均为 `status=collected`，含当年计划来源、现站已采集行数、专业组缺口、检查时间及已观察的可点击前端入口。不是声称取得全校所有类型或完整组码。
- `sources.json`：21 份本年初始计划查询、4 份省考试院征集计划、2 份官网直接链接的电子指南入口，共 27 份公开来源。
- `supplementary-plans.json`：84 条属于这 8 校的**本科普通批第一、第二次征集剩余计划**。不能加入初始计划表，不能用于首轮自动匹配。每行保留当轮学校、专业组、省编专业代码、计划类别、培养方向、再选要求、学费、备注；明确 `plannedCountScope=remaining-supplementary-plan`、`evidenceRound`、`firstRoundMatchAllowed=false`。

本批**新增初始专业组码为 0**。这是一项有证据的边界：没有把后续征集组码、校内专业序号或同名专业当初始组码补入。

## API 核查结果

重新请求全部 21 份已有初始计划来源，均成功读取。广西大学、广西民族大学、广西医科大学、广西财经学院的 12 个公开 API 条件查询，每行均为 2026、广西（45），行计划数与接口 `overview` 汇总一致；返回的 `major_group` 全部为 `-`。南宁师范 API 返回 196 行（含此前不进入普通计划集的其他类别），`zygroup` 全为空。没有未使用的真实三位组码可从这些字段直接补回。

`major_num` 也不能假设为广西省编专业代码。例如广西大学初始 API 翻译 `major_num=45`，省第一次征集表专业代码为 021；建筑学分别为 20 和 046。两者不能依数字补零建立映射。高校系统的国家专业代码、校内专业编号、省编专业代码必须区分。

桂电、桂理工原初始计划已经直接列组码，本批没有用后续阶段覆盖。广西师大原计划没有专业组字段。此前已证实的广西大学校内“一组/二组”指南及广西医大空正文专业分组入口，本轮不重复采作新证据。

新找到民大官网直接链接的 `2026年报考指南`（sqje，公开浏览器可读 6 页）和 `2026年招生指南`（wtiv）。报考指南计划总表含预科直升口径，未取得可直接替代本年初始分省专业组字段的数据。来源目录标明电子指南入口属性，不宣称其中组码已采集。

## 验证及复现

`QA.json` 核验：11 条初始记录人数与组码未变；84 条征集数据全部禁止首轮匹配；源年、省份、接口汇总、文件哈希和冲突断言通过。4 份省表使用 GB18030 解码并展开合并单元格，不使用网页乱码输出。

脚本均为本目录相对路径，不依赖旧私人研究目录。需要 Python，表格展开另需 `pandas`、`lxml`：

1. `python3 reproduce.py --fetch` 重放 `public-request-manifest.json` 中公开请求并展开官方表格。
2. `python3 build.py` 重建交付并运行断言。

`baseline-plans.json`、`baseline-sources.json` 是开始本批时公开网站数据快照；未修改。`raw/` 仅公开来源，不含考生信息。重新抓取时官方内容如变化，应另建新审计批次，不能冒称历史哈希核验仍成立。
