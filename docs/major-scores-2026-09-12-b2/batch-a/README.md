## 来源和数据边界

- `major-cutoffs-upsert.json` 为待导入增量空数组；`sources.json` 与 `school-audit-notes.json` 为有效增量。
- 所有来源 ID 和审查 ID 使用 `20260912b2-a`，不会覆盖上一轮同校核查记录。
- 15 个本年成功空响应与 4 个旧年正对照分别列于 `query-evidence.json`；访问失败记录不计入成功查询。
- 60 份完整原文及元信息仅留本地 `raw/`。原响应 hash 与脱敏归档 hash 分开保存；错误 JSON 中的会话字段亦移除。访客 Cookie、CSRF 值不写入公开文件。
- 公开摘要仅供查询范围、年份与事实核对，不含完整 HTML/JS/PDF/图片/接口表。`source-snapshots.json` 是来源元信息快照。
- 山东原图已目视确认只有类别汇总列；不将类别/组分数、计划人数、旧年数据、第一次投档口径或综合成绩当专业实际分。
- 本轮没有分数行，因此未补写未知专业组、位次、批次、轮次、资格或实际人数。

## 可移植复现

Python 3.9 或以上，全部脚本只需标准库；不依赖公共仓库代码、父级工作目录或账户。在本包目录执行：

```sh
python3 build.py
python3 verify.py
```

这两步仅使用公开白名单内的冻结摘要，可以离线运行。审核日期取自 `review-context.json`，不会在次日重建时变化。

如需重新查询官方来源：

```sh
python3 replay.py
```

脚本只请求 `public-fetch-manifest.json` 中已核查的公开入口和前端接口；保留本轮失败请求以展示排查过程，并执行最终成功的农大 HTTPS/会话请求。`replay-results.json` 与重采原文只写本包。来源状态或 hash 改变时会提示人工复核，不自动替换已审核结论；动态页面 hash 改变也可能只是访问时间变化。

本轮检查依赖的原文已重新取得且经过人工审核后，可运行：

```sh
python3 freeze_evidence.py
python3 build.py
python3 verify.py --raw
```

此步骤会替换本包的证据快照，不能在未审核新响应时运行。断言会阻止源数量、菜单、旧年正对照或成功空响应发生未审核变化；图片列义、首轮/实际录取口径仍需人工复核。原站恢复、出现本年专业行或要求新的公开字段时，应更新解析和证据，而不是继续沿用本包零新增结论。

只发布 `PUBLIC-FILES.json` 明列文件，禁止递归复制研究目录。`raw/`、缓存、临时请求清单和重采响应均不公开。
