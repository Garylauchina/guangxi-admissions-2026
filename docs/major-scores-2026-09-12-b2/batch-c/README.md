## 分数与资格口径

重庆城市管理职业大学表头明确“录取专业、录取最低分数、录取数”；[2026章程](https://zs.cqc.edu.cn/2026/0615/c1594a92875/page.htm)按分数优先确定专业，认可生源省加降分规则。**婴幼儿托育服务与管理不录取色盲、色弱考生**，两科记录均已保留这一硬条件。公共外语统一英语；本批普通专业大一在荣昌校区，后续回大学城校区。学校现名与广西当年投档目录一致，代码12758，章程标识码4150012758；未根据域名或升格推断新的学校或校区代码。

铜陵图题为“2026年高考录取进程”，列出广西、本科批、物理-化学、具体专业、录取人数、最高/最低/平均分，**没有投档分表头**。地理信息科学最低453、土木工程最低448，各录取5人，原图平均分分别464和453.2。7月25日为录取日期，不用于推定首轮。[2026章程](https://zsb.tlu.edu.cn/2026/0601/c1750a129215/page.htm)明确以投档分录取并按生源省政策处理加分，教学第一外语为英语。

渭南图表头原文为“文化分投档 录取最高/最低分”，说明列为“文化分录取”，另列计划数和实际录取数。本包根据**2026录取快讯、逐专业录取数、文化分录取说明**保存实际专业录取分，同时逐行保留 `sourceScoreHeader/sourceScoreNote` 及混合措辞解释。它没有标“首次投档最低分”，也不被改称不含加分的裸分。[2026章程](https://zsb.wnu.edu.cn/info/1015/2416.htm)及[学校迎新专栏同版章程](https://xgb.wnu.edu.cn/yingxin/info/1008/1045.htm)明确按政策加降分后成绩排序。**旅游管理计划4人、实际录取3人**，只保留3人的成绩统计；没有用人数差异推断征集，也未用实际人数替换初始计划。

32条的组码和位次均无直接字段，保持 `null`；没有转换或猜测位次。全部轮次保存为“录取汇总（轮次未分）”。渭南公告未写精确本科批次，保存为“本科（批次待核）”；铜陵保留原表本科批，重庆保留高职专科批次。除铜陵明确物理-化学外，不推断其他再选科目“不限”。录取表未单列加分数值时如实说明，不把总分误称裸分。

## 可移植复现

在本包目录运行：

```sh
python3 collect.py
python3 build.py
```

只用Python标准库，目录名和父项目名不参与解析。`requests.json`列出实际访问的官方URL；`raw/`保留完整原HTML、图片、元数据与哈希，**不公开**。公开包第一次复现需先采集；官网变更或访问失败时不得沿用旧断言。归档齐全后可离线构建，不需要当前线上仓库。

`baseline-context.json`保存本次1058条/26校历史基线摘要、另20校排除目录和学校代码对应关系，`code-sources.json`保存已有考试院校码来源；它们不表示之后线上库仍有1058条。`importer-preflight.json`只是本次基线的只读预检，未来应由仓库实际导入器检查新增或已导入状态。

`image-transcription.tsv`和`evidence-rows.json`只保存原图/表公开统计事实，行号从各图第一数据行起算；重庆HTML行号含表头，因此从2开始。原图计划数仅在证据转录中保存，没有进入计划库。`PUBLIC-FILES.json`列出可公开文件，排除所有原网页、图片、缓存和响应元数据；不保存或公开Cookie、会话、签名或个人资料。
