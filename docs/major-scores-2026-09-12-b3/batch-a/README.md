## 离线复现

仅需 Python 3 标准库。从本包目录执行，放在公共仓库 `docs/major-scores-2026-09-12-b3/batch-a` 同样可用，无仓库数据或私有目录依赖：

```sh
python3 build.py
python3 verify.py
```

`build.py` 依据公开的冻结来源元信息、字段检查摘要与审核日期重建三份增量 JSON 及 QA；不会从旧年摘要产生本年分数。`verify.py` 检查证据计数、日期、来源引用、学校代码与公开白名单。这是离线结构和边界复核，不能代替重新读取官网。

## 在线重采与本地原文复核

```sh
python3 replay.py
python3 freeze_evidence.py
python3 build.py
python3 verify.py --raw
```

`replay.py` 仅请求 `public-fetch-manifest.json` 列出的公开地址和已观察到的字段，普通匿名 Cookie/CSRF 在内存处理；广州所用 `Authorization: tourist` 是页面明确公开的匿名标识，不是账户凭据。若响应状态或 hash 变化，脚本提示人工重新审阅并退出，不能把变化自动转为新结论。新响应中的动态时标、网页内容或匿名会话变化均可能导致 hash 变化。

原文写到本包 `raw/`，不公开。`freeze_evidence.py` 需要本地原文并逐份验证 hash、年省科类和本轮计数；网站数据改变时，其冻结断言会失败，需要复核后更新，不能宣称同样结论。

仅发布 `PUBLIC-FILES.json` 白名单。原始 HTML、JS、JSON、验证码内容、身份认证页、个人名单及会话值均不包含在公开包中；JSON 归档移除会话/CSRF/临时分页标识，原响应只记录 hash。公开摘要仅用于来源核对，不是另一个旧年分数数据库。`archiveFile` 是本地原文定位，不承诺公共下载。
