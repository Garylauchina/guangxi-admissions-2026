## 可移植复现

脚本均仅需 Python 3 标准库，路径相对脚本目录；不依赖个人电脑绝对路径。原始 HTML/JS/JSON/Excel/图片留本地 `raw/`，公开白名单不包含这些原文。

持有原始材料时，离线重建和核验：

```sh
python3 build.py
python3 verify.py
```

重新采集：按数字顺序用 `collect.py requests.json`、`collect.py requests-2.json` 至 `requests-10.json` 读取页面及已查前端的公开接口；随后依次运行：

```sh
python3 session_query.py session-requests.json
python3 session_query.py session-requests-2.json
python3 shu_query.py
```

Cookie、CSRF 令牌及 FineUI 会话状态仅在内存使用；原始响应指纹与脱敏归档指纹分别保存，正文会话值已移除。`shu_query.py` 根据现场表单提取隐藏状态和前端控件，提交公开筛选值；不使用保存的会话。`collect.py` 对省考试院采用原页声明的 GBK；Excel及图片保持原二进制。

在线重采可能遇到官网更新、接口变更或访问失败；当前查询清单是冻结审查的参数，不应在无人工复核时把新返回自动当已审核数据。`audit-context.json` 固定本次审核时刻，离线重建不调用当前时间。独立审阅及重新采集后的审核时间需有意识地另设新审查批次。

本目录只按 `PUBLIC-FILES.json` 白名单公开。白名单中无会话值、私人路径或个人考生信息；图片的长图及裁切阅览件均留本地。
