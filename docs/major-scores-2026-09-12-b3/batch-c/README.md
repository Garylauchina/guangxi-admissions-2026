## 口径与保留的缺口

- 咸阳原列名是“投档录取最低分”，栏目明确“普通类专业录取情况”，同时列计划、录取和退档人数，按专业实际录取分收录，保留 `sourceScoreHeader`。`sourceTieBreakOrder` 仅指“录取最低分同分排位”，不是全区位次，`rank=null`。化工前表计划3、录取2、退档1、缺额1；随后征集487分的1人独立保存，未覆盖前表440分。
- 未从公告日期推首轮；未明示轮次的记录使用“录取汇总（轮次未分）”，征集保留“征集（次数未分）”。宝鸡、咸阳快讯未明确广西精确本科批次，因此保留“本科（批次待核）”。所有省组码未知，不拿专业代码替代。
- 成都原图“中医骨伤学”用 `sourceMajor` 保留；同校、同年、同省、同科类唯一计划项目写“中医骨伤科学”，据此规范展示名称并双源引用。公开计划查询返回14行，12条普通物理/历史与两条体育；计划数据只佐证名称、类别，未更新招生计划或实际人数。
- 成都药学、智能医学工程及康复治疗学在本次广西计划中为普通类，不带合作项目后缀；未把全国章程中的同名中高计划或中外合作办学条件套用。四校章程的语言、色觉等限制分别写入专业备注；护理身高等建议保留为建议。
- 普通750分总分允许学校认可的政策加分；原表未拆出加分值，不称“裸分”。一分一档未用于伪造实际专业位次。
- 昆明医科、浙江农林已读公告只有科类/学校投档汇总，未拆成专业分；广西科技官方主页虽链接2026数据，但微信返回环境验证页，记录为仅入口，不称成功空表。其他只作为检索线索的学校不作穷尽性结论。

## 文件与复现

仅 `PUBLIC-FILES.json` 列出的文件允许公开。完整 HTML、图像、接口响应和抓取元信息保存在本地 `raw/`，不在发布白名单。源表事实在 `evidence-rows.json`；图像手录在 `image-transcription.tsv`；各来源记录公开URL和SHA-256。已有考试院来源仅复用其校码事实，未重采或将专业组投档线当专业分。

在本包目录运行：

```sh
python3 collect.py
python3 build.py
```

第一步会重新访问 `requests.json` 中实际发现的公开网页和查询；网络失败、网页更新及动态阅读次数可能使新原档哈希变化。`collect.py` 不记录HTTP头、Cookie或CSRF。成都计划请求严格按公开页面实际的 `Year/Province/MajorName/page/limit` 字段提交，接口没有个人查询参数。

若持有本轮本地原档，只运行 `python3 build.py` 可离线重现冻结事实。复现不依赖仓库位置；已在不含网站的临时 `docs/.../batch-c` 目录复制执行验证。公共库不携带原档，故公开下载需先抓取才可完整重建，不把网络获取结果保证为永久不变。

`importer-preflight.json` 是对1120条历史基线的只读导入检查：新增67、更新0、预计1187条/34校、3校缺口记录。合并其他批次后这些合计会增长，不能当作当前站点总量。构建的 QA 检查原档哈希、来源闭合、表内线差/人数加总、分数上下界、均分区间、禁止基线覆盖和目标重叠等。
