## 复现与边界

将本目录与 `batch-c` 放在同层，在 C 保留/重新取得原始档案的条件下执行：

```sh
python3 review_c.py --bundle ../batch-c
```

仅需 Python 3 标准库；脚本只读 C，生成本目录的审阅结果，不依赖私有路径或 C 的解析器。`cdutcm-independent-transcription.tsv` 是目视转录的事实核对表，不是原图复制。公开文件列于本目录 `PUBLIC-FILES.json`。

本审阅覆盖四校全部 67 条正源转换及对应资格证据，不宣称独立核完 C 的其他学校负面结论、所有历年目录、所有官方发布渠道或个人报考资格。源表未给出的组码、位次、精确批次、分专业人数等缺口仍存在。
