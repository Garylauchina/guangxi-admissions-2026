## 复现

Python 3 标准库即可，无第三方依赖。

```sh
python3 fetch_evidence.py --manifest public-fetch-manifest.json
python3 fetch_nju_public.py --normal
python3 build.py
python3 validate.py
```

运行目录为本文件目录。`build.py` 同时读取上一级锁定的 `targets.json`，不修改它。首条下载命令可能因保留的早期裸请求 403/404 或内容哈希变化以非零状态退出：这是预期的证据告警，应先检查请求记录，再决定是否构建。南京正常查询必须运行第二条命令，不能拿第一条的早期失败覆盖已读计划。南京查询删除响应顶层会话字段 `jessionid`：`sha256` 与 `archiveSha256` 为脱敏归档哈希，`responseSha256` 为原响应哈希；不保存 Cookie 或令牌。不得把错误页当成空计划。成功源内容变化时，需重新阅读并更新核录及预期哈希后才能发布新数据。

离线复现（已有 `raw/`）只需运行后两条命令。公开复现脚本和人工核录仅包含学校级聚合招生计划，不包含学生画像或个人信息。
