# 2026 广西高分目标组：A 批来源核查

核查范围固定为北京大学本部 10001、北京大学医学部 19001、清华大学 10003 的 7 个目标首轮组。没有用其他院校替代目标，没有改动网站、Git 或部署。

本批新增专业计划 **0 条**，新增可匹配目标组 **0 个**；7 个目标均为 `entry-only`。已核查不等于已补齐。`plans-upsert.json` 为合法空数组，可以导入来源目录和核查记录，但不能把本批计为计划覆盖增长。

| 院校代码 | 科类及目标组 | 结果与缺口 |
| --- | --- | --- |
| 10001 | 物理 102、历史 101 | 北大备用官方域名可读，取得 2026 全国招生指南、普通高考及咨询入口。指南为全国专业介绍，未提供广西初始分专业计划。 |
| 19001 | 物理 101 | 医学部计划栏目只列 2025、2024、2023。可读广西表明确属于 2025，不导入。2026 咨询微信链接要求环境验证，未获取正文。 |
| 10003 | 物理 103、历史 104 | 旧版计划查询公开界面年份为 2010–2014。按公开前端字段查询 2026 广西理工/文史统招，均返回空数组。不能把全国专业类介绍当作广西投放计划。 |
| 10003 | 物理 602、历史 601，高校专项 | 2026 广西理工/文史“专项计划”旧接口查询均为空；旧界面也未细分高校专项。自强栏目最新简章为 2025。不得使用旧年专业、国家专项或强基专业替代。 |

所有目标的本组专业组成、分专业及组内计划总人数、再选科目、学费、学制、培养与报考限制均未获得足够的直接证据，保持未采集状态。

主要证据与限制：

- 北大原 `www.gotopku.cn` 入口返回证书过期错误；通过搜索找到官方 `bkzs.pku.edu.cn`，证书正常，可以继续读取。未关闭证书校验。
- [北大 2026 招生指南](https://bkzs.pku.edu.cn/docs/2026-06/ea87b5bdc4c2436787106a463d1d6bb0.pdf)目录及印刷页 199–202 经目视核验：专业表为全国专业一览，随后是 2023–2025 分省录取分数，没有广西 2026 初始计划人数。目录及相关页不能据以分配广西组码。
- [医学部历年计划](https://bkzs.bjmu.edu.cn/zsxx/zsjh/index.htm)的 2025 广西链接路径含 `2022`，正文明确为 2025。年份判断使用正文与导航，不能只看路径。
- [清华旧版计划查询](https://bk.join-tsinghua.edu.cn/student.bz_bzw_zsjh.do)的 `nf/sf/kl/jhlx` 与 `m=queryByCon` 来自公开前端脚本。2026 广西四项查询为空；使用相同参数编码查询界面列出的 2014 广西数据可以返回记录，作为阳性对照。旧年对照记录不进入计划数据。
- 清华 [2026 咨询公告](https://join-tsinghua.edu.cn/info/1033/2197.htm)中的广西图片经目视核验，仅有咨询教师、电话、地点、项目联系人，未列招生专业和人数。
- [广西官方完整计划入口](https://zyfz.gxeea.cn/Main/Jihua/JH_Chaxun_New.aspx)公开访问重定向到登录页。没有登录、破解或绕过验证。该结果不表示学校没有公布计划。

可接入文件：

- `plans-upsert.json`：空数组，保留现站已有计划。
- `sources.json`：17 条入口或缺口证据；`usable2026GuangxiPlan` 均为 `false`，旧年证据明确标注真实 `sourceYear`。
- `source-catalog.json`：3 校目录，状态均为 `entry-only`。北大没有可核实的分省计划查询地址，因此不伪填 `entryUrl`；另两校 `entryUrl` 是已观察到的旧年计划入口，备注明确年份局限。
- `target-results.json`：逐目标记录结果、缺失字段、来源、核查时间与已访问网址。
- `access-evidence.json`：公开访问结果，不含登录凭据、学生信息或网页会话标识。
- `QA.json`：本批边界及检查结果。

复现：需要 Python 3 标准库，无私人工作区依赖。运行 `python3 fetch_public.py` 按 `request-manifest.json` 重新请求公开页面和只读查询，随后运行 `python3 build.py` 校验哈希并重建结构化成果。若官网内容更新导致断言失败，需重新审阅，不应跳过年份或空结果检查。

`raw/` 和分阶段调试日志保留本地即可，不建议随站点公开。公开文件名单见 `PUBLIC-FILES.json`。搜索候选中的“2026参考”旧年转载未用作计划或来源证据。
