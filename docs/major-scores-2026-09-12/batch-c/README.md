## 口径与缺口

广西中医药大学[本科普通批页面](https://www.gxtcmu.edu.cn/zs/zsjz/content_88882)原图40行含2条预科，[专科普通批页面](https://www.gxtcmu.edu.cn/zs/zsjz/content_89174)5行合计399人。两者分数字段均明确为“首次投档最高/最低/平均分”，**全部未进入实际专业录取分库**。本包只保存其来源及排除说明，亦未更新现有专业投档分库。录取人数或页面题名不足以改变原表分数性质。

定向项目的正式专业名保持“中医学（定向医学生）”，各县区写入 `serviceArea/serviceCity/serviceCounty`，并在 `admissionType` 中区分，避免同一专业组内不同定向服务地记录互相覆盖。报考资格、农村户籍和连续3年要求、设区市生源限制、签协议、培训/专硕完成后至少6年服务等，依据[2026政策百问百答的官方院校转载](https://www.glc.edu.cn/zsw/info/1008/2891.htm)及[学校2026章程](https://www.gxtcmu.edu.cn/zs/zszc/content_87648)逐条保留。未推定再选科目“不限”。

78条均未明确轮次，统一“录取汇总（轮次未分）”。定向72条组码来自原图直接字段；浙江工商组码为空，其原公告只标高职专科层次，具体批次保存为“高职（专科）（批次待核）”。所有原表均不提供位次，全部 `rank=null`，没有转换、猜测或混用旧年位次。最低/最高分及1人录取记录的一致性全部通过。原表计划数只在转录证据中保留，未用录取人数填计划。

北京联合大学2026页面的广西段只有12条专业组分数，无具体专业列，列为本轮缺口。另曾读取的 sxyyc.net 页眉确认属于已收录重庆三峡医药高等专科学校，未重复采集。其余搜索结果没有达到实际专业分证据标准，本轮不凑3–5校。

## 复核与复现

- `major-cutoffs-upsert.json`、`sources.json`、`school-audit-notes.json`：正式增量包。
- `evidence-rows.json`：HTML原行或原图人工转录单元格；只含公开统计事实。
- `gxtcmu-early-transcription.tsv`：原图72条逐行转录，行号从表头后第一数据行起计。
- `excluded-records.json`：首次投档、预科、组线及已收录学校排除说明。
- `QA.json`、`importer-preflight.json`：核验及现行导入器只读预检结果。

在本包目录运行（适用于工作目录或公共仓库中的 docs 目录）：

```sh
python3 collect.py
python3 build.py
```

`build.py` 从本包的 `code-sources.json` 和 `baseline-context.json` 读取固定校码来源与历史基线，不依赖执行时的线上库或父目录名称。`importer-preflight.json` 记录的是本次948条基线上的历史只读预检，并不声称稍后仍可新增78条。若在已导入的公共仓库重新预检，应运行仓库自身导入器，并以当前库的结果为准，不使用本包历史数目作断言。

采集脚本仅请求 `requests.json` 中公开文件，网络请求可能因官网变更而改变或失败。两个阳光高考政策原网页直取为HTTP412，右江镜像为TLS错误，不当作空数据；政策事实由可完整读取的桂林学院官方转载提供，并已核对。失败请求留元数据，不作为有效来源。先有对应原始归档才可离线执行构建；公开包不附原网页或图片，首次复现须先运行采集。

本轮无PDF。浙江工商HTML表已完整读取并按原生行合并展开。广西中医药提前批2张、普通本科2张、专科1张原图均已目視检查；本科第二图是第一图的延续，但不进入实际分数。提前批PNG有透明背景，查看原文件时黑字可能与阅读器黑背景混合；`raw/*-white.png`只是以白色背景显示的检查预览，没有更改原图或数据。原响应和图片哈希与归档逐项核对，原文件不上传。

人工转录另放大核对合并边界：历史图第19行、物理图第30行均为河池市宜州区，分别属于407/457组；贵港市408/458组从下一行桂平市开始。初稿的县区和归组误录已在正式包修正，分数和人数无改动。独立审阅又发现物理图末行上思县数字误读，原图放大确认最高/最低均为575，已把初稿576/576改正；此项是正式导入前的转录修正。

`PUBLIC-FILES.json` 是公开白名单；排除所有 `raw/`、缓存及原网页、图片，不保存Cookie、会话或签名值。脚本使用相对路径，不含私人绝对路径。独立审阅结论由父任务另行归档。
