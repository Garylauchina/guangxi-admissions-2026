## 证据与公开边界

- `sources.json`：每次请求的官方入口或前端直接关联接口、公开参数、原响应 hash、归档 hash、北京时间采集日期。CDN/API 域名由学校本轮公开前端直接引用，有对应 JS 来源。
- `school-audit-notes.json`：稳定 ID、`auditKind=major-scores`、本地复核日期、逐校覆盖范围和访问缺口。
- `query-evidence.json`：不含原始完整记录的事实核对摘要，包括两科/类别、空数组结论、校区值、年份统计和来源引用。
- `source-snapshots.json`：离线构建所需的冻结来源元信息。
- 完整原始 HTML、JS、PDF、JSON、PDF 提取文字及请求元信息仅保存在本地 `raw/`，**不公开**。字典中的后台维护字段、验证页内容也不复制到公开摘要。仅允许发布 `PUBLIC-FILES.json` 明列文件，不应递归复制本目录。

`responseSha256` 校验实际收到的响应字节；`sha256` 校验本地归档字节。JSON 去除会话键并格式化，两个 hash 可能不同；HTML/JS/PDF 未改写，两个 hash 相同。公开摘要是衍生证据，不冒充原始字节。所有来源本轮重新访问，未复用昨日响应作当日采集证据。

## 可复现流程

本目录内离线重建与验证：

```sh
python3 build.py
python3 verify.py
```

构建只读本包冻结摘要，不依赖旧项目或私人路径，也不访问网站目录。当前网站导入器的纯预检应只更新来源与核查台账，不添加专业分。

重新在线采集：

```sh
python3 replay.py
python3 extract_bnu.py
```

`replay.py` 仅请求公开白名单中的入口、真实前端调用地址与字段。北交/北科走正常匿名会话，沙河采用前端的公开 JSON POST，其余为正常 GET。没有账号登录、持久化 Cookie 或认证值。遇访问验证页不会执行挑战。所有重采响应只存 `raw/`；响应 hash 或状态变化时脚本报需人工复核，不自动提高覆盖状态。动态 HTML 的 hash 变化未必等于数字变化。

`extract_bnu.py` 需要可用的 Python `pypdf` 包，提取的本地文字也留在 `raw/`。人工重新核对来源后，可执行 `freeze_evidence.py` 再生成新快照；脚本对空结果、字段含义、整表行数与旧年边界均有断言。新响应若出现本年数据，应先人工审核与更新构建逻辑，不能继续把本包当作空结果。
