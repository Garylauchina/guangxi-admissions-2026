# 全量采集的独立质量与规模验收

2026-09-12，基于本地仓库 `1e8e991acb3a41f37ca1693703195de494bc7360` 的只读设计。没有抓取新数据、修改站点或启动定时任务。验收对象是“完整列明目标、逐项有证据核查、可取得的合格数据已发布、外部缺口真实可见”，不把学校未公开的专业分承诺为一定可补齐。

## A. 目标分母必须可以重算

阶段 0 以 `inventory.json`、`special-inventory.json` 和 `summary.json` 保存逐条清单、输入文件及 SHA-256、纳入规则和来源文件。每次发布由 Git 提交固定范围快照；后续阶段另存范围版本及差异，不能覆盖旧版本证据。阶段 1 补充方便人工分工的 CSV 派生清单，不能只有“共多少校”的文字。

当前 `site/coverage.js` 仅用首轮投档线、计划、专业实际分构建院校集合，并把所有学校标记 `partial`。因此不能只读取 `school-coverage.json` 就宣称全网站学校已经枚举完整。独立验收应对照网站所有实际加载并展示院校的文件，包括征集投档、补充计划、专业投档分、特殊招生等；只出现于某一路径的院校也必须有记录，或有明确的“另一路径单列”排除理由。

建议保存两层清单：

- `D_site`：当前网站所有可展示的 2026 学校实体及其数据路径，代码缺失或冲突的记录进入身份待核清单，不静默丢掉。
- `D_major`：其中需要进行广西普通高考专业实际分核查的学校/校区代码；艺体、强基、保送、职教等另建路径任务，不能用不适用规则提高普通专业采集率。普通高考国家专项、高校专项、地方专项、定向、公费师范和合作专业保留其独立类别。

验收公式：每个 `D_site` 条目恰有一个范围判定；`D_major` 中每个条目恰有一个学校主任务，但可以挂多个入口和组合子任务。输出 `missing-targets`、`duplicate-targets`、`unexpected-targets`、`unresolved-identities` 明细；前三者应为空，身份未决数量及具体原因必须公开可核。

招生专业分母单列为 `D_plan_known`，仅表示现已核实的本年广西计划实体，包含学校代码、批次、科类、组码、广西专业代号、专业/大类、类别及计划版本。未知字段不得伪造唯一匹配。**未获得完整官方分专业计划时，不计算“全专业录取分完整率”，也不把现有 1,970 条计划或 1,255 条专业分当作全广西专业总数。** 可以计算“现有已核实计划中的可精确关联比例”，但必须同时显示有限分母、未知项和未匹配原因。

## B. 学校代码、校区和专业身份

五位学校代码保持字符串；同校异名维护显式别名表，记录官方考试院目录或当年章程等身份依据。名称相同但招生代码不同，不合并；代码相同但出现异名，先检查更名、独立校区、历史译名和来源错误。不能仅凭域名、升格、更名公告标题、学校简称或相似度决定合并。

至少以现有真实案例作为身份回归：华电北京 `10054` 与保定 `10079` 独立；山东大学威海 `19422` 与本部独立；校区参数不同的查询不能转移记录；重庆城市管理职业大学的现名与 `12758` 要由同年考试院/章程支持。官方链接至委托招生平台的授权链也属于身份证据。

专业名称保留 `sourceMajor`，名称规范仅在同校、同年、同省、同科类和同类别的可靠证据支持时发生。官方不同文档之间的冲突不自动修正；陕师“电子信息技术/电子信息科学与技术”的待核记录应继续退出比较。国标专业代码只进 `sourceMajorCode`，不得写成广西填报代号。

## C. 每条 CSV/JSON 记录的字段来源

JSON 为结构化权威副本；CSV 是无损可核对的派生展示文件，明确 UTF-8、引号规则、空值约定和字段说明。学校码、专业码作为文本；分数保持实际小数，不四舍五入制造整数；缺失值不写 `0`、“不限”或空字符串混合语义。CSV 导出若可能由表格软件执行公式，应使用明确的导出保护，但不改变 JSON 原始字段。

为每行提供 `id, sourceId/sourceIds, sourcePage/sourceTable/sourceRow, reviewedAt`；关键字段（学校身份、统计年、省、科类、专业、最低分、分数口径、批次/轮次）都要能定位到表头、正文或字段级来源。排名、专业组、再选科目、人数等补充字段若来自另一个文档，使用 `fieldSourceIds`，不能让全行同一来源链接暗示所有字段出自成绩表。

独立检查包括：

| 检查 | 必须满足的条件 |
| --- | --- |
| 统计年份 | 原表、查询年或正文证实 2026；2026 发布的 2025 分数不合格；页面模板按请求年份生成标题不单独构成年份证据 |
| 地区和科类 | 明确广西、物理/历史；错误默认省份、中文乱码、未确认的“综改”不强制映射 |
| 分数含义 | 明确具体专业/正式大类实际录取最低分；学校/组/科类汇总、首次专业投档线独立存储；强基/艺体综合分不进入同一 750 分比较 |
| 分数口径 | 加分/实考分依当年章程和表注；750 分满分不能推出裸分；最高、最低、均分之间矛盾则退出比较 |
| 轮次与批次 | 未注明则待核/录取汇总；征集不改首轮；一张公告录取日期不能推断轮次 |
| 人数 | 实际录取人数与计划数分列；全省/全表人数不拆成逐专业人数；零录取不能生成实际最低分 |
| 字段语义 | 先读本校表头，不能凭 `xkkm` 推断选科；首都医科该字段是年制 |
| 去重和更正 | 精确身份去重，加人工审查近似重复；已有行更正保留稳定 ID、旧值、新值和字段依据 |

CSV 重读后应与 JSON 核心字段逐行一致，行数、唯一 ID、学校代码集合、录取类别集合一致。专业行、汇总行、排除行数量分别守恒，不能靠删掉无法解析的行让校验通过。

## D. 完整来源范围与整校完整的区别

`source-scope-complete` 需要同时满足：有完整菜单或完整公告/附件清单；每个本年广西相关组合已请求；分页总数与返回行数一致；跨页续表和图序列已遍历；每行标记为入库、重复、待核或明确不适用。表头、脚注与补充更正附件都已检查。该状态只属于确切来源、类别、批次和观察版本。

`school-scope-complete` 还需要学校本年所有广西录取路径、批次与轮次有完整官方依据，并且不同官网栏目、录取快讯与查询系统不存在未检查的应纳入范围。普通类完整不能代替专项完整，某份“全部专业”表也可能只覆盖一批。没有该证明时保留 `partial/unknown`，不根据已取得较多条数升级。

现有可测例：海大当前 9 类组合取得 60 行并排除预科，可以说明该查询范围已完整处理；首医本年菜单 6 专业与 6 结果一致，可以说明该表范围完整；陕师当前 PDF 只明确 2 专业，不能把同页 12 行类别汇总拆成其余专业。对外经贸 30 行的完整表也不自动证明未明示的轮次完整。

## E. 缺口状态独立验收

以下状态不能混为“未发布”：

| 观察状态 | 证据最低要求 | 不允许的推论 |
| --- | --- | --- |
| 本年有效空数组 | 参数正确、业务成功、结果数组为空；请求作用域可回溯；能取得时另存旧年同条件正对照 | 学校没有招生；所有渠道均未发布 |
| 明确无匹配 | 成功读取业务提示及对应请求；如广州 code9999 | 按成功空数组统计；未查询类别也已覆盖 |
| 本年菜单不存在/仅旧年 | 真实当前菜单/原表内容及统计年；记录已检查范围 | 未来不会发布；全部网站没有本年分数 |
| 传输或业务失败 | 具体错误、请求方法、时间；没有内容则不伪造内容哈希 | 错误响应代表无记录 |
| 访问验证/登录 | 页面类型和限制事实，未完成挑战的说明 | HTTP200 代表已读取 PDF/成绩表；未提交查询算空表 |
| 仅汇总/仅投档 | 正文/表头证明统计层次及口径 | 用专业计划数把一条学校分拆成多条专业分 |
| 未定位来源 | 列明官方主页、已查栏目/公开替代渠道和方法范围 | 未定位等于确定未公开 |

每个学校可同时有“查询空表”和“另一官方 PDF 有部分专业分”，不能用一个较新的空表覆盖此前有效分数。旧年正对照用于验证查询语义，不进入本年录取数据。所有负面状态的说明限定于实际完成的入口和条件。

## F. 专项和其他招生路径

普通高考中的国家/高校/地方专项、民族班、定向、公费师范、优师、合作办学等作为独立类别；资格、履约、收费及语种/体检条件在详情保留。即使分数可按相同量纲比较，也不能让不具资格的用户把特殊类别误当普通录取机会。

强基、竞赛相关保送/专项、综合评价、艺体与单招另做路径和成绩口径说明。综合分、校测、入围线、资格条件、录取名单不是同一种“专业最低录取分”；页面提供来源和当前状态，而非硬塞进普通分数筛选器。个人录取查询和含考生姓名/证件信息的名单不采作公共专业统计证据库。

## G. 原资料和公开产物

原始网页、完整 API 响应、PDF、图片与会话上下文保存本地受控证据区；发布显式 `PUBLIC-FILES.json` 白名单。每次公开差异检查确认不含 Cookie、CSRF、FineUI 隐藏状态、个人数据、内部路径或完整版权正文。匿名学校固定 ID 与个人/会话凭据分开处理，不用黑名单单一正则代替人工检查。

证据链必须能区分抓取的原响应哈希和去除会话字段后的归档哈希，时间使用冻结观察时间。离线重建只能证明冻结事实可复现；不能宣称重新核实官网。若重新访问得到改变的表，生成新观察版本和待审变更，不原地改写历史审核结论。

## H. 完整省计划到来后的增量范围

发现完整官方 2026 广西计划册/授权公开表时，先独立核对目录、页码/分页、修订及增补说明、批次、科类、院校/专业组/专业代码和人数；不能仅凭文件标题“全册”就扩大分母。

确认后生成 `scope-v2`，保留 `scope-v1` 及完成情况。差异报告逐项列出新增学校、改名/代码别名、新组和专业、取消/调整计划、仅征集/补充路径、与既有实际录取分的精确/不确定匹配。新增范围进入增量任务；已经具备有效来源且范围未变化的记录不重复采集，已有学校新增类别或专业则只补相应子任务。

计划的完整性只证明计划实体范围，不能证明每个专业都有考生录取或必须公开最低分。分专业实际录取的可得性仍逐项标记：有直接分数、官方说明未录取、官方未给专业分、名称/类别待匹配、尚未核查。没有官方零录取证据时不能用空白当零录取。若展示“计划项匹配到专业分比例”，须标明是计划匹配指标，不能称“实际录取专业完整率”。

## I. 何时可以说全量核查已完成

只能对一个明确日期和不可变范围版本作此结论，且同时满足：

1. 所有 `D_site` 条目已完成范围/身份判定，所有 `D_major` 学校任务都有适用的本轮来源检查及结果；未尝试、排队、待解析、待审核任务为零。
2. 每个来源的本年广西菜单、分页、附件范围都已检查或列出外部访问/公开缺口；当前可由自动或人工处理的异常已经解决，没有把软预算耗尽直接当完成。
3. 可取得且符合范围的专业实际分已独立复核并发布；来源矛盾与不可比较数据已标记；旧年、汇总、访问失败等缺口有正确分类及可定位证据。
4. 目标清单、逐校状态、来源范围、排除项、数据变更、测试与部署核验都可下载/查看，统计可由脚本重算；分母和最终状态没有遗漏或重数。
5. 页面已展示已收录数据和余下缺口，用户能区分待发布/访问受限/尚无直接专业分；所有跨年、学校、科类、分数口径与来源跳转的阻断缺陷为零。

若存在外部未公开或访问受限，可准确表述“截至某日，对范围版本 v1 的全部学校完成本轮公开来源核查，取得 X 校 Y 条，另 Z 校仍有已列明外部缺口”。不能简化成“全部专业录取分已收齐”。若仍有未执行或待人工核实的学校，只报告进度，不能宣称全量核查完成。

## J. 独立检查与规模闸门

采集、解析和最终复核尽量由不同执行者完成；复核必须读取原证据/真实表头和字段，不只重跑生成同一 JSON 的脚本。结构化 API/HTML 对全部候选行进行独立字段核对与数量守恒；PDF/图片关键数字、专业名和脚注逐行人工复核。任何跨年、跨省、错学校、投档冒充录取的错误应阻断该来源适配器后续自动入库，追溯同解析版本全部已产生行。

全量阶段先用混合来源样本测入口发现率、适配率、人工审核耗时和异常占比，再估算剩余量；不得用新增条数推算学校已完整。进度至少分别统计学校任务、有效来源范围、实际专业行、冲突行、已知计划匹配、未公开字段和外部缺口。

复用现有导入器、`npm test`、`npm run check` 和精确提交部署检查。`scripts/report-score-review.mjs` 目前只支持纯追加并保护所有旧记录/来源逐字不变；需要更正时新增“经独立复核的字段更正清单”验收分支，验证其他旧数据仍完全不变，不直接删除保护断言。最终用实际浏览器验证新增专业检索、科类/分数筛选、专项标签、冲突退出比较、无数据状态及来源定位。

验收通过记录应该给出精确提交和已执行检查；没有执行的线上/视觉/来源复核不能用“构建通过”代替。本设计文件本身不是后续采集或发布的验收通过证明。
