# 100校试运行 A：已有计划、缺专业实际录取分的20校

核查日：2026-09-12。本轮20个院校代码均有实际读取的官方证据；共136次页面、配置和统计请求。原始网页、API响应和本地基线仅保存于raw，不发布。

## 结果

- 本轮没有新增可以直接参与比较的专业实际录取分。
- 广西财经学院取得117条专业统计候选（物理71、历史46），全部为**年份冲突待核**。官网链接的查询配置标题与年份菜单只标2025，但2026查询的专业行均写year=2026、province=45；2025对照是另一组108条记录。不能只凭API年份把它判为已核实2026，117条均scoreComparable=false。9条类别汇总不进入专业库。
- 另取得55条专业投档候选：广西师范大学14条（物理7、历史7），广西工程职业学院第一次征集41条（物理20、历史21）。它们独立放在supplementary-major-filing.json，不混入实际录取分。
- 广西师范大学原文“政治与行政学”名称存在差异，保留原称、暂不比较；其他54条投档候选需保持投档口径。
- 其余19校分别留下旧年、当年空响应、投档口径或访问失败的具体结论。空响应和访问失败不代表学校未招生，也不证明全网没有公开资料。

## 重现与验收

1. collect.py接受requests-*.json，按已声明的官方入口或前端请求字段读取；每个域名顺序处理，最多3个域名并发。collect_public_api.py使用官网正常匿名Cookie与CSRF流程，会话仅在内存使用，归档移除会话字段。不存在账号登录或验证码绕过。
2. 离线原始证据齐备时运行`python3 build.py`生成公开统计事实和有限范围核查结论；运行`python3 qa.py`校验20校覆盖、逐条字段、哈希、空响应和年份冲突退出比较。
3. 根目录的`node scripts/import-major-score-batch.mjs <本包目录>`只读预检通过：117条待核新增、20条核查记录，未修改站点数据。supplementary-major-filing.json需单独复核导入，不能送入actual major importer。
4. public API配置会变化，重新联网后必须重新复核数据年、省份、类别、页数和说明，不能仅重跑旧断言后自动发布。

117条候选不继承2025页面中“正投、不含征集”的说明；所有轮次保持未分，组码未知。专业最低位次来自同一响应的major_columns和major_data_source.lowest_position。来源隐藏num字段未当作已核实录取人数导入；国家专业代码不当作广西填报码。

PUBLIC-FILES.json为唯一发布白名单；raw目录、完整基线及任何会话资料不得复制到公共仓库。
