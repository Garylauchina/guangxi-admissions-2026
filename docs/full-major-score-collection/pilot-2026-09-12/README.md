## 试点结论与后续顺序

四组的目标不同，成功率分别计算，不能合并后推算全区能采得多少数据：

- 有分缺计划组：20 校中 14 校取得合格初始计划，采得率 70%；另 6 校保留旧年、空目录、访问失败或科类未拆分等具体缺口。
- 新核查本科组：30 校中 5 校取得实际专业分；22 校所查入口仅旧年，2 校本年有效空表，1 校查询入口访问失败。
- 有计划缺分组：20 校本轮未取得新增可比较实际专业分；取得的专业投档及年份冲突另表保留。
- 广西及高职新核查组：30 校本轮未取得合格实际专业分。典型资料为旧年统计、其他考试通道、学校或专业组线、只有录取名单或日程。

接下来按主台账中的物理、历史高分顺序推进未查学校；已证实的公开接口族优先复用，但逐校验证菜单、省份参数和分页。高职保留独立任务份额，每累计 100 个新核查任务做一次覆盖检查；不因某校仅有旧年资料反复重试，也不因分数靠后永久跳过。

随后对 25 所已同时拥有计划与分数的学校做逐专业、科类、类别、批次和轮次对账。逐字同名仅作候选，组码、专业代码和计划人数不能靠相同分数、国标代码或实际录取人数推断。受限来源及未拆科类的计划另列疑难队列；原有 4 条冲突本轮重查仍缺直接修正证据，继续保留。

强基及竞赛目录的 43 项仍按独立任务表处理，本批没有把其入围线、综合成绩或资格信息混入普通专业分。院校条目合并继续暂缓。

本轮采集交错进行，记录了证据首末时间和部分请求耗时，没有完整的逐工序人工计时。不能把学校时间跨度相加或把单个成功接口的速度外推到全部剩余学校，因此不承诺未经测量的完工天数。后续批次需分别记录来源发现、提取和独立复核的实际耗时，再更新工作量估算。

## 核验与复现

数据经过来源行数核对、原表字段比较、关键 PDF/图片视觉复核和独立复核。三峡医专的“预防医学（物理）4 人”在第二次视觉核查中补回；陕师合作分数 PDF 哈希与旧源一致，既有两条继续保留。

网站将可比较分、待核分及专业投档分分开展示；新增待核学校筛选，并修复新模块遇到旧缓存时无法加载的问题。全部 12 个 JSON 请求使用共同内容版本，避免新分数与旧计划混用。验证结果另见 [release-checks.json](release-checks.json)。

只公开各包白名单中的统计事实、脱敏来源元数据、采集脚本与核查说明。完整网页、全国 API 原响应、PDF、图片、会话及个人名单不入公开仓库。历史逐字重建依赖本地原始归档；重新请求官网可能取得后续变化的内容。
