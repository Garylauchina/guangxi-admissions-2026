# 2026 广西专业录取分核查：B30

本批仅核查 `targets-public.json` 的30所本科高校，范围包含物理与历史。学校按历史类顺序排入本批，不代表仅核查历史类。全部结论是列明渠道、时间和查询组合的有界核查；未取得不等于未招生，也不等于所有官方渠道均未发布。

新增可导入专业分69条：上海海事大学36条、浙江工商大学30条、中央美术学院3条。共物理51条、历史18条。原始统计均指2026广西，轮次未细分的保留“录取汇总（轮次未分）”。专业组码、广西专业填报码和位次均未推定。

另交上海政法学院5条官方专业组录取最低分候选。它们来自官方2026本科录取分数线表的完整广西专业组行，与专业分增量分开；没有从部分专业求最小值，也没有将投档表充当录取表。国家专项两科未列专业组码，未进入候选。

## 核查边界

- 上海海事：从实际表单枚举2026广西物理/历史各8类，共16组合；普通物理29、提前物理2、普通历史5，其余13个查询明确返回没有结果。只对已查组合做空结果判断。章程明确按投档分安排专业，政策性加分计入专业录取。选科要求从结果表直接提取。
- 浙江工商：官方全表1688行，逐行筛统计年2026和省份广西得32行，排除2条少数民族预科后为30条。最高/最低/平均分逐列核对；专业（类）的成员文字保留，不拆分为各专业分数。接口的 `planNumber` 不在可见表中显示，既不转成录取人数，也不充当初始招生计划。2026章程PDF前两页经渲染目视核对。
- 中央美术：2026本科非校考专业标准图的广西段共3行；按章程普通本科条款确认投档成绩与加分口径。仅采普通高考750分口径，未收校考、艺术综合成绩。采集代理与根代理分别目视核对3行。图上的招生计划没有转成录取人数或另作招生计划导入。
- 27所未新增专业分学校分别保留来源与缺口：24所为统计年或数据粒度缺口，广东外语外贸大学本轮官方栏目无可读文章，宁波大学公开表单字段请求401，西南民族大学官方入口412。失败请求不算空表；尚未解析的动态入口也不假称已经查询本年所有结果。
- 厦门大学马来西亚分校保持20384独立身份，未混入母校10384。

## 文件与证据

`major-cutoffs-upsert.json`、`sources.json`、`school-audit-notes.json` 供现有增量导入器预检/集成。`observations.json` 给出30校的核查范围、仍存缺口、访问结果和时间。`evidence-rows.json` 保留69条对应的统计字段及原表/JSON定位；`source-manifest.json` 给出原响应与本地档案散列。`group-admission-candidates.json` 是单独的5条组分候选，不能混入专业分导入器。

`build.py` 仅读取本目录本地证据，生成本目录文件，不改网站。`collector.py` 与 `api_collector.py` 为公开查询采集辅助；同一主机串行并保留请求间隔，不绕过验证码或访问限制。有效匿名CSRF会话仅在内存使用，未发布会话值。

所有完整HTML/JSON响应、PDF、图片、下载脚本依赖的原始材料和请求清单只留本地。**仅 `PUBLIC-FILES.txt` 列明文件可公开**，禁止递归复制整个目录。公有包仅含采集/提取脚本、相关统计事实、说明和脱敏来源元数据；缺少raw时不能重建，需按来源重新取得官方材料。

## 验证

本地检查核对69条逐行年省/科类/字段定位、最低最高平均分关系、未推断组码或位次、所有使用档案散列和30校审计齐全。现有 `scripts/import-major-score-batch.mjs` 仅运行只读预检，结果见 `preflight.json`；未执行apply，未修改网站或Git。

来源时间为实际访问UTC时间。逐校首末证据跨度包含与其他学校交错执行的时间，不能当作独占人工工时或直接相加估计吞吐。全部学校保持 `scopeComplete: false`，表示完整覆盖工作仍需按缺口继续。
