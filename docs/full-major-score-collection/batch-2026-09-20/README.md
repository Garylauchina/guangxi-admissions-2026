# 2026-09-20：100 校补采与展示更新

本轮核查 100 个此前尚无独立专业分核查记录的院校代码，新增 10 校、278 条可比较的 2026 年广西专业录取最低分；另收录 2 校、8 个专业组的官方最低录取分。此批不代表全量采集完成。

## 已发布内容

- 移除“专业招生计划”“专业录取分数”两个顶层标签；专业资料保留在院校专业组详情和逐校资料入口。
- 专业组卡片并列显示“2026年投档线”和“2026年最低录取分”。后者只接收直接发布的组级录取统计，缺少依据显示“待补齐”。
- 8 条组录取分均为未分轮次的年度汇总，页面与导出明确标注；不能据此比较本次征集与首轮录取成效。

## 当前覆盖及剩余缺口

当前 1,961 个院校代码中，52 校已有部分可比较专业分、254 校已核查仍缺可比较专业分、1,655 校尚待独立核查。可比较专业分共 1,672 条，另有 121 条原文待核；初始计划仍为 2,380 条、49 校。本轮未增加初始计划。

本轮其余 90 校没有新增专业分；原因包括仅有旧年菜单、仅公开投档或学校/组级汇总、当前菜单为空、入口访问失败。各类分别记录，网络失败不记为有效空查询，2026 发布的旧年表不改年入库。详见各包 school-audit-notes.json 和 observations.json。
