## 数据口径

- 仅使用明确 2026、广西、具体专业或正式专业类的实际录取最低分。API逐行检查 `nf`、`ssmc`，不能只相信请求参数。
- 地大北京依据2026章程采用实考总分，不含政策加分；石油华东、宁夏和川美普通类按认可政策加分后的总分。`scoreBasis` 保留差异。
- 民族班、国家专项、高校专项独立保留；不把艺体、校考、强基、预科或学校/组汇总拆为具体专业。
- 87条均未知广西3位专业组码、广西填报专业代号及首次/征集轮次。全国专业代码和学校组选项名只保存原文。不得根据相似专业或部分专业最小值反推组线。
- `group-admission-candidates.json` 为空。地大北京确有 `sszyzgradeList` 的2026录取汇总，但只列“物化1”等名称，缺少直接广西组码；南信大2026公告明确写“投档分”，不能替代录取最低分。
- 19141只核盘锦校区；19359只核宣城校区，母校或另一校区数据未混用。

## 重建与后续重采

本地冻结原始证据存在时，运行 `python3 build.py` 可重建统计包。它只读本目录raw并写本目录，不联网，不改站点。固定条数断言是本次冻结校验，后续新证据必须人工复核后调整，不能静默替换。

`collector.py` 为普通官方页面/GET及简单POST采集器，POST负载字段名为 `data`；`api_collector.py` 为匿名前端API采集器，POST负载字段名为 `request`。`api_collector.py` 支持正常匿名cookies和CSRF，不需要账户登录。实际请求及参数已记录在 `sources.json`，错误调用也保留，并明确方法差异。

两个采集器同一进程内对同主机加锁，并在请求完成后至少间隔1秒；不同主机可以并发。后续重采应使用一个协调进程，避免在多个进程同时请求同一主机。不要绕过验证码、登录或浏览器安全警告。该约束不能证明跨进程或历史所有请求均串行。

`observations.json` 的首末请求跨度含并行、中断和等待，只是观察区间，并非主动工时；本轮旧请求缺少逐次耗时，不能把跨度相加作全量工时估算。
