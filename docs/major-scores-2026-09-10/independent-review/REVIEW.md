# 专业实际录取分新增批次独立审阅

2026-09-10：**可供整合；本次已报告的问题均修复并独立复测，未留阻断项。** 审阅只写本目录，未修改网站或数据包。

## 导入器与页面

复现并确认修复：专业实际分被额外组参考分覆盖；明示不同满分制仍可比较；来源征集却标首轮；最低分证据缺口与可比较标记矛盾；非专业分字段冲突被过度阻断；原始资格类别未纳入一般筛选；明确零录取人数生成实际最低线。类别待核计划排除出一般筛选是更谨慎的边界，不表示原界面曾承诺这些全部为普通类。

修复后，错年、错省、以上错误比较反例均被拒绝或排除；可证专业分仅有其他字段冲突时仍保留比较。记录有资格限制不等于分数无效，仍可在全部类别中按其原口径查看。高考总分按高校官方加分口径处理，不要求一律为裸分。

独立执行导入、逻辑、页面交互相关 **13 个测试，全部通过**。详情保留原始最低分及冲突说明；分数不可比较时卡片、分差与导出不使用该分。原始轮次未分的记录保持汇总标签，不因碰巧等于首轮或征集组线而改写轮次。具体反例、修复状态、文件哈希见 [review-results.json](review-results.json) 与 [importer-probes-fixed.json](importer-probes-fixed.json)。

## 桂林医科大学 C 包

独立编写另一套表格读取逻辑，没有调用采集代理的解析器。逐行核对年、省、科类、批次、组码、专业、最高、平均、最低、类别与来源行；核验公开请求参数、配置映射及归档字节哈希。

| 核验项 | 结果 |
|---|---:|
| 官方完整分页 | 7 页，10×6＋2＝62 行 |
| 配置与逐组回包 | 32 配置项、31 个唯一查询组，62 行 |
| 纳入具体专业实录分 | 57 条，26 个组 |
| 科类 | 物理 51、历史 6 |
| 类别 | 普通 34、定向医学生 17、民族班 1、中澳项目 5 |
| 排除预科 | 5 条，逐行与排除文件一致 |

57 条与原始逐组响应完全一致；分页与逐组结果的多重集完全相同。40 条普通批/高职记录的院校、科类、批次、组码还能与既有考试院组表交叉对应；17 条提前批定向记录有学校配置及回包直接证明，未借普通批组码推定。未公布位次、计划人数、实际录取人数的字段未推算。

人工另读了 10 条关键原表单元格，包括定向组 450/451、历史 101、普通 155、民族 750、中澳 950/952/953、高职 184，最高/平均/最低列未错置。155 组中不同专业最低分确有差别，未把组最低分复制成专业最低分。

本校[2026 招生章程](https://jyw.glmu.edu.cn/zhaosheng/school!articleDetail.htm?recruitArticle.searchArticleId=145)已独立实时读取：中澳五专业与“中高计划”对应，英语门槛为 90/150，其他满分按 60%。最终 5 条记录已补这一门槛及章程字段来源。章程亦证明高考投档总分和专业录取处理口径，含政策加分不构成不能比较的理由。

## 再现与范围

`review_c.py` 使用 Python 标准库，接受 C 包目录和网站数据目录参数；完整重算需要重新采集或本地保留的 C 包 raw 归档。`probe-importer.mjs` 使用 Node.js，接受仓库目录及可选结果输出路径，只有合成反例，不写网站。测试记录见 [regression-tests.txt](regression-tests.txt)。

本审阅不代表对所有学校、全部旧来源或网站所有功能重新检查。程序验证不能替代每条来源的事实审核。可公开文件严格以 [PUBLIC-FILES.json](PUBLIC-FILES.json) 为准。
