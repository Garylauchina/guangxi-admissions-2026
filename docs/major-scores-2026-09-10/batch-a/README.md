`major-cutoffs-upsert.json` 只包含河南城建学院 16 条，不包含其他 7 校的旧年或推测记录；不能把其他 7 校缺口标为已补齐。河南城建“城市地下空间工程（数智岩土方向）”原文为最高 423、最低 418、平均 428.2，平均高于最高；三项全部原样保留，`scoreComparable=false`、`evidenceStatus=source-conflict`，详情见 `source-conflicts.json`。其余 15 条的平均分均位于最低与最高之间，最低减控制线均与原表线差一致。

河南城建 2026 招生章程第 14 条以高考投档成绩为依据、第 19 条认可政策加分。该批按普通高考总分参考，不称为剔除加分的裸分；表中未单列加分处理方式，已在 `scoreBasis` 和备注保留。原表未列广西正式批次、专业组、最低位次或录取人数，故这些字段不推测；首轮与征集也未分开。

## 复现

需要 Python 3.9 或更新版本，仅使用标准库。从此目录执行：

```sh
python3 replay.py
python3 build.py
python3 verify.py
```

`replay.py` 只访问 `public-fetch-manifest.json` 列出的官方网址和公开只读接口。它读取正常匿名页面会话，按官网公开脚本流程获得 CSRF 值；不登录，不使用账号，不保留 Cookie 或 CSRF 值。归档 JSON 递归移除会话字段，`responseSha256` 记录原响应摘要，`sha256` 记录脱敏归档摘要。动态会话字段可导致原响应摘要变化；复现检查使用脱敏归档摘要。

所有路径相对于脚本目录，不依赖旧研究目录或本机用户目录。网页或数据变化会使复现检查停止，须人工重新核查后才能更新事实与摘要；不会把新出现的 2026 记录静默丢弃成空数组。

原始网页、接口归档、请求调试文件留在本地 `raw/`，不在公开白名单中。公开内容以 `PUBLIC-FILES.json` 为准；重放时可重新生成原始证据。结构检查通过仅证明本批交付与缺口证据一致，不代表资料已经补齐。
