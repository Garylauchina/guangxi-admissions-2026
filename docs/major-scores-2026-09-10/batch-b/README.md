# 2026 广西专业实际录取分：批次 B

本批实际收录重庆师范大学 11 条专业最低分（历史 5、物理 6），其中 1 条明确为征集。交大本部、交大医学院、复旦、浙大、南大的当年广西专业分暂未取得，已分别保存实际官方查找证据。未使用 2025 分数、学校/专业组投档线或预测数据补空。

主文件：`major-cutoffs-upsert.json`；来源：`sources.json`；六校复查说明：`school-audit-notes.json`；排除详情：`excluded-records.json`；校验：`QA.json`。公开发布仅按 `PUBLIC-FILES.json` 白名单纳入文件，`raw/` 和请求临时记录不发布。

## 重庆师大来源与边界

[学校官方录取结果](https://zsb.cqnu.edu.cn/info/10438/88323.htm)发布于 2026-08-08，统计截至 2026-08-08。完整表有 370 行，全部解析至最后新疆单列类行，广西共有 19 行。保留 11 行单一专业或正式大类；广西的 3 行艺术分与 5 行多专业合并最低分全部排除，其他省份 351 行全部排除。

食品质量与安全 547 原注“征集”，单独标 `征集（次数未分）`。其余 10 行原文未列首轮，所以标 `录取汇总（轮次未分）`。专业组、专业代码、位次、最高分、平均分、计划人数和实际录取人数均未公布，均为空。地理科学类是原表单一正式大类，不能拆成内含各专业分。

省份物理/历史两科原文批次“本科批”规范为“本科普通批”，同时保留 `sourceBatch` 和原科类。10637 校码仅用广西考试院组线表核对学校身份；不从该表推专业分或专业组。

## 原五校缺口

- 交大本部官方历年分数栏目最新数据年为 2025；医学院官方最新分数文章也是 2025，且两者保持独立校码。
- 复旦官方分数栏目最新为 2025 分省录取分数。
- 浙大 2026-06-17 发布文章的实际标题是“2025年浙江大学各省份普通本一批投档分数线”。发布日期不等于数据年份，投档分层级也不等于专业实际录取分。
- 南京分数前端和正常公开查询可访问，广西可选年份仅 2025/2024/2023。用前端实际参数字段对任务指定的 2026 普通物理/历史做缺年探查，两次 `state=1`，省级及专业级列表均为空。没有把空结果转成 0 分，也未根据旧年菜单猜测 2026 专项类别。

缺口表示当前实际来源未提供符合口径的数据，不表示学校不招生，也不声称所有可能发布渠道已穷尽。`sources.json` 的 `sourceDataYear/year` 是内容实际数据年；`queryYear=2026` 是本批调查目标年，不能混同。

## 复现

仅需 Python 3 标准库。在本目录运行：

```sh
python3 fetch_evidence.py --manifest public-fetch-manifest.json
python3 fetch_nju_scores.py --probe-current-missing
python3 build.py
python3 validate.py
```

离线复现（已有 `raw/`）运行最后两条即可。下载成功但哈希变化时必须重新审阅；构建过程也会检查公告标题、全表行数、排除数与负面空响应。如果南京开始返回 2026 数据，构建会要求重新审核，不会继续把它记为空。

南京流程由官网公开 `tplt.js` 确认：普通页面建立 Cookie 会话、公开 CSRF 获取、时间戳和同站表单查询。会话值只存在内存；响应顶层 `jessionid` 删除后归档。`responseSha256` 为原响应哈希，`sha256/archiveSha256` 为脱敏归档哈希，查询参数保留。可选 `--all-current` 只按当前分数菜单实际出现的广西 2026 物理/历史类别遍历，不猜类别。
