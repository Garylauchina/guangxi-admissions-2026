# 广西志愿参考 · 2026

[打开网站](https://garylauchina.github.io/guangxi-admissions-2026/) · [数据来源说明](DATA-NOTICE.md) · [校验结果](docs/validation.json)

一个面向广西考生的免费静态志愿筛选参考工具。查询 **2026 年**本科/高职普通批院校专业组投档线、已收录的专业招生计划与专业实际录取分，查阅强基和竞赛相关升学通道。

## 使用

1. 选择首选物理或历史，输入 2026 年分数，或输入需要对照的 2026 参考位次。
2. 按分差、批次、轮次、资格筛选，搜索院校或已收录专业。
3. 在“专业招生计划”查看人数、已知选科、学费与学制；在“专业录取分数”看高校公开的真实专业最低分。
4. 查看每条记录的官方来源，加入备选并导出 CSV。备选仅存本机浏览器，输入分数不上传。
5. 在“强基与竞赛”逐校确认广西招生范围、当年资格及分数口径。
6. 在“院校数据缺口”查看逐校覆盖、缺失字段和本轮官网复查记录。

## 覆盖与缺口

2026-09-10 深审已发布：[修复与缺口报告](docs/audit-2026-09-10/README.md) · [前后统计](docs/audit-2026-09-10/summary.json)。移出 87 条不适用普通高考筛选的计划、合并 2 条重复分列并新增 20 条公告计划；计划总条数下降不代表减少招生。

- **2026 普通批投档**：16 张广西招生考试院原表，11,448 条记录，其中首轮 8,155 条，涉及 1,961 个院校代码；征集 3,293 条，分别保存轮次。
- **一分一档**：物理/历史全国性加分口径，共 1,010 个公开分数档；未公开档不插值。
- **专业招生计划**：18 校、1,615 条（其中部分为录取公告明确列出的计划数，详见记录备注）；**专业实际录取分**：13 校、720 条；**强基**：39 校目录、34 条广西入围或综合成绩，另有 4 个少年英才项目、8 条竞赛与招生政策。
- **专业招生计划、专业实际录取分、强基广西计划/成绩：部分覆盖。** 最新记录数、学校列表与广西状态在网站“数据与方法”及 `docs/validation.json` 中展示。全区官方计划查询的登录限制和本次检索结果见 [访问核验](docs/province-plan-access.md)。不能将此项目称为全区所有高校所有专业的完整招生数据库。
- 普通批原表中的专项、预科、民族班、定向等备注保留。默认排除识别到的资格限制，但仍需核对未在投档表完整列出的条件。
- 本科提前批、艺术、体育和各类单独招生未做全量采集，不混入普通类分数比较。

**专业组投档线不是专业录取线。** 只有年份、院校代码、院校名称、科类、批次、专业组码全部一致才关联专业计划与首轮组线。计划组码未知时保持未匹配。来源未给精确投档位次，`rank` 一律为空；一分一档的同分区间不能冒充精确投档位次。

分差只表示相对 2026 年线的位置，不是录取概率；不输出“保录取”或未经验证的冲稳保概率。跨年需要重新核对计划、组内专业与位次。

## 本地运行与检查

需要 Node.js 24 和 Python 3。网站没有运行时第三方脚本、账户或后端。

```sh
npm ci
npm test
npm run check
npm start
```

本地打开 `http://localhost:4173`。直接双击 HTML 文件无法读取 JSON，需使用 HTTP 服务。

## 更新数据

`site/data/` 是前端使用的结构化数据；`scripts/` 保存采集和校验程序；`docs/` 保留核验记录。原始下载文件应放 `raw/`，该目录被 Git 排除。

- `scripts/collect-cutoffs.py --refresh` 重新下载列明的 16 张 2026 原表，逐单元格双解析交叉验证。
- `scripts/collect-ranks.py` 下载 2026 两科官方一分一档表，校验名次区间和累计人数。
- `scripts/collectors/` 保留完整普通批/专业录取线与 14 校计划的独立采集程序，具体重建顺序见各目录 README。
- `scripts/import-data.py <public-research-directory>` 导入明确指定的公开研究成果，检查年、来源和唯一编号。
- `scripts/collectors/audit-2026-09-10/` 保存本轮公开来源获取、纠错及复核程序。独立复核还修正医大提前批细分与重庆工程学院不限选科规则。
- `python3 scripts/integrate-audit.py <audit-directory>` 合并已审阅的三个研究包；`python3 scripts/build-school-audit-notes.py <audit-directory>` 生成复查台账；`node scripts/build-coverage.mjs` 重建逐校缺口。完整流程见本轮报告，不要用旧采集结果覆盖新审计结论。
- `node scripts/validate-data.mjs --write-report` 写入检查报告。投档表记录数变化需要人工审阅，不能直接修改校验基线绕过检查。

新增专业计划必须提供官方来源、实际年份、科类、批次和计划人数。不得猜测未知专业组、选科、分数与广西强基招生范围；不得将录取人数作为计划人数或用学校最低线给专业赋分。重新采集后应先核对差异、运行测试，再发布。

## 部署

GitHub Pages 发布目录为 `site/`，通过 GitHub Actions 在 `main` 更新后先执行数据与交互检查再部署。仓库的 Pages 构建方式须设为 GitHub Actions。拉取请求只验证，不部署。

个人整理项目，不隶属于广西招生考试院或任何高校。正式填报使用[广西招生考试院](https://www.gxeea.cn/)与[广西阳光志愿](https://zyfz.gxeea.cn/)等官方渠道。
